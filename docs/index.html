Build notes

Cloudflare Compose is a local stdio server. Claude Desktop, Claude Code and Codex can run it on the operator’s machine. A hosted ChatGPT or claude.ai connector needs a separate authenticated remote transport; this project does not publish credentials or an anonymous gateway.
